# BaccaAI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build BaccaAI (Kanti Baca Batang Hari) from `D:\aplikasi untuk meta.md`: a Next.js PWA where Batang Hari children read local stories aloud, get gentle syllable-level correction, and co-create the next illustrated page, with all app data stored only on drive D.

**Architecture:** Next.js App Router + TypeScript + Tailwind on `D:\bacca-ai`. PostgreSQL 17 cluster owned by the app at `D:\bacca-ai\pgdata` (port 5433) via Drizzle ORM (`users`, `stories`, `story_pages`). Meta goes through one provider adapter: HTTP provider inert until real Meta docs/keys arrive, local fallback provider implements the exact PRD section 6.2 JSON using browser speech/typed input, heuristic accent-tolerant evaluation, template story continuation, and locally generated SVG illustrations stored in `D:\bacca-ai\storage`.

**Tech Stack:** Next.js (App Router), React, TypeScript, Tailwind CSS, Drizzle ORM + pg, PostgreSQL 17 (binaries at `C:\Program Files\PostgreSQL\17\bin`), Vitest.

**Spec:** `D:\aplikasi untuk meta.md`; design: `docs/superpowers/specs/2026-10-27-bacca-ai-design.md`

## Global Constraints

- Everything app-owned lives on D: code, `pgdata`, `storage`, `backups`, `.env.local`. Nothing is written to C or cloud as a fallback.
- No Meta keys exist: fallback provider is the tested path; HTTP Meta provider activates only from `.env.local` env and is never guessed against a real endpoint in tests.
- Child audio is never stored as a file; only transcripts are stored.
- Palette `#10B981` / `#065F46` / `#FFFFFF` / accent `#F59E0B`; fonts Fredoka (display) + Plus Jakarta Sans (body); big bottom record button; mobile-first.
- Age enforced 6-10; subdistrict closed enum of the 8 PRD kecamatan; `accuracy_score = correct target words / total target words * 100` rounded; max 3 tricky words in reading order.
- Accent tolerance is matching-only normalization (trailing -o to -a etc.); it never marks a Jambi-Melayu pronunciation wrong.

## Review Focus

- Mic/speech unsupported or denied -> typed path must complete evaluate and continue.
- Meta HTTP failure/timeout (20s) -> local fallback with `"provider": "local-fallback"`, never a child-facing error screen.
- DB down -> API 503 `{error}` and a friendly retry UI; no silent write elsewhere.
- Imagination input with markup/very long text -> escaped in SVG/prompt, truncated server-side, story still continues.
- Empty transcript -> 400 from evaluate, praise flow does not advance or fabricate a score.

## File Structure

- `lib/content/themes.ts` — 4 themes, seed stories (pages 1-2), kecamatan list; one responsibility: static local content.
- `lib/reading/evaluate.ts` — tokenize/normalize/syllabify/score; pure and unit-tested.
- `lib/meta/provider.ts` — provider interface, local fallback continuation + PRD 6.2 JSON, inert HTTP provider shell.
- `lib/meta/image.ts` — themed SVG illustration generation to storage.
- `lib/db/schema.ts`, `lib/db/index.ts`, `scripts/migrate.mjs`, `scripts/db-*.ps1` — Drizzle schema, pool, DDL, D-cluster lifecycle.
- `app/api/users/route.ts`, `app/api/stories/route.ts`, `app/api/stories/[id]/route.ts`, `app/api/stories/[id]/evaluate/route.ts`, `app/api/stories/[id]/continue/route.ts`, `app/api/summary/route.ts`, `app/api/images/[...path]/route.ts`
- `app/page.tsx` (profile + themes), `app/baca/[id]/page.tsx` (reader), `app/ringkasan/page.tsx` (dashboard), `app/manifest.ts`, `public/sw.js`, `components/*`.
